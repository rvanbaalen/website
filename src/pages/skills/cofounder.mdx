## When to use

Use when you need a thinking partner who pushes back. The Cofounder agent enforces prioritization, challenges assumptions, and holds you accountable. It grounds itself in your actual business context on first run, then gets sharper the more you use it. Useful for check-ins, sparring on ideas, reviewing progress, or doing focused business work.

## How it works

1. On launch, the orchestrator derives a project-scoped ID from your working directory so multiple cofounder instances can coexist across projects. A legacy unscoped config is migrated automatically.
2. First run triggers setup to create the workspace, then an onboarding intake conversation that populates goals, topics, and the up-next queue with real content.
3. On later runs it validates the workspace structure and spawns the cofounder agent with your business name, type, stage, and primary metric as context.
4. The agent detects which check-in is overdue by reading the daily log and the weekly, monthly, and quarterly review archives — no session-type menu. Higher cadences subsume lower ones (quarterly > monthly > weekly > daily), and it offers the overdue one before anything else.
5. If you open with clear intent instead ("got an idea", a direct question), it skips the cadence prompt and routes straight to sparring or focused work.
6. Goals cascade downward — north star, quarterly, monthly, weekly focus, daily check-in. Goals are never rewritten upward to justify what you actually worked on.

## Getting started

```
/plugin install cofounder@rvanbaalen
/cofounder
```

First run triggers setup and onboarding automatically.

## What's new in v1.2

- **Automatic cadence detection.** The agent reads your check-in history and works out which review is due instead of showing a session-type menu. It respects clear intent and skips the prompt when you arrive with a topic.
- **Onboarding intake conversation.** A dedicated `onboard` skill replaces empty template files with real goals, topics, and priorities after setup.

## Invoke

/cofounder What should I focus on this week?
