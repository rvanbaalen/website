## When to use

Use when text is locked inside an image or a scanned PDF: receipts, business cards,
contracts, screenshots, archive scans. The skill wraps a bundled Python module
(`scripts/ocr_processor.py`) that drives Tesseract, so it also works as a plain CLI
outside Claude.

## How it works

1. Loads the input (PNG, JPEG, TIFF, BMP, or PDF — all pages or a page subset)
2. Optionally preprocesses the image: deskew, denoise, threshold, contrast, sharpen,
   upscale, shadow removal
3. Runs Tesseract with the requested language(s) and page segmentation mode
4. Returns text plus blocks, lines, words, per-word confidence, and detected language
5. Exports to Markdown, JSON, HTML, or a searchable PDF

## Capabilities

- **Structured extraction** — bounding boxes per block/line/word with confidence scores
- **Multi-language** — 100+ Tesseract languages, combinable (`eng+fra+deu`) or `auto`
- **Preprocessing** — cleanup pass for noisy or skewed scans before recognition
- **Table extraction** — tables out to CSV or JSON
- **Searchable PDFs** — re-emit a scanned PDF with a text layer
- **Document parsers** — receipts (vendor, date, line items, tax, total) and business
  cards (name, title, company, email, phone, address, website)
- **Batch mode** — `batch_ocr()` over a directory, recursive, with a success/failure count
- **Tunable config** — PSM, OEM, DPI, timeout, minimum word confidence

## Requirements

The Tesseract OCR engine must be installed on the system, along with language data
files for any non-English language. Python dependencies: `pytesseract`, `Pillow`,
`PyMuPDF`, `opencv-python`, `numpy`.
